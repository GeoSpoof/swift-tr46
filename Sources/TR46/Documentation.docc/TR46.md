# ``TR46``

Convert domain names between their Unicode and ASCII forms with the same results as tr46.

## Overview

This package is a Swift port of [tr46](https://github.com/jsdom/tr46) 7.0.0, jsdom's
implementation of [Unicode IDNA Compatibility Processing (UTS #46)](https://www.unicode.org/reports/tr46/),
and of the Punycode encoder and decoder from
[punycode.js](https://github.com/mathiasbynens/punycode.js) 2.3.1. Its data is Unicode 18.0.0.

It gives the same result as tr46 for every input and every combination of options, quirks
included, so a Swift app can agree with jsdom, whatwg-url or a browser extension that uses tr46.
It has no dependencies and runs on Apple platforms and Linux with Swift 6.0 or later.

```swift
import TR46

TR46.toASCII("Bücher.example")         // "xn--bcher-kva.example"
TR46.toUnicode("xn--mnchen-3ya.de")    // (domain: "münchen.de", hadError: false)
```
